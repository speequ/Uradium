Step-by-step tutorial on how to configure the AI:

1.Go to https://console.groq.com/keys and make a API key, then, go to mybot.py through notepad (or VSC) and locate the line: client = Groq(api_key=os.environ.get("Your API key goes here")) ,delete the text inside the quote and add in ur API key.

2.Right click on yeah.bat and edit in Notepad,find the file mybot.py in the folder the AI is in and press Ctrl+Shift+C. Then, replace "C:\path\to\your\mybot\folder" with ur path. (but delete the mybot.py part)

3 (Optional). Right click mybot.py and edit in Notepad, then below "default_instructions = (" u can set ur own rules etcetera in quotes.

It should be working, if it doesnt, i dont know honestly. Just try to examine whats wrong because i also had some issues. Using the AI is simple. Just open yeah.bat and done.
